# Router-1x3-RTL-Design---Verilog
This repository contains a Verilog RTL implementation of a 1x3 Network-on-Chip (NoC) Router. It features an FSM controller, a parity-checking register block, a synchronizer, and three 16-byte FIFOs. It routes packets to designated ports based on header addresses and verifies data integrity. A testbench is included for validation.
